3. Risques Résiduels et Recommandations de Mise en Production

Risque Résiduel Faible

En cas de coupure réseau brutale pendant l'upload d'un gros fichier, le serveur doit nettoyer les fichiers temporaires orphelins (tâche cron recommandée).

Recommandation Version 2

Intégrer les tests Playwright dans la pipeline Jenkins automatique à chaque Pull Request pour interdire toute régression visuelle.
